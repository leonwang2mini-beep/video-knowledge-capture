# 视频知识捕手 · 使用指南

## 第一次使用

### 1. 准备 Inbox

在 Obsidian 中新建一个专门接收视频笔记的文件夹，例如：

```text
D:\我的知识库\00 Inbox
```

复制这个文件夹的完整路径。应用不会自动寻找或创建真实知识库目录。

### 2. 启动应用

双击项目根目录中的：

```text
start-video-capture.cmd
```

保留弹出的启动窗口。浏览器应自动打开：

```text
http://127.0.0.1:43127
```

如果浏览器没有自动打开，可手动复制上述地址。

### 3. 保存落点

展开页面底部的“设置与恢复”，在“Obsidian Inbox”中粘贴完整路径并保存。

- 显示“已就绪”：可以开始采集。
- 显示“待配置”或“需检查”：根据页面提示确认路径是否存在、是否为文件夹、是否可写。

配置只记录本地文件夹路径，不包含 Obsidian 账号或任何平台凭据。

## 日常收录：只粘贴链接

1. 复制公开视频链接。
2. 粘贴到首页唯一的链接框。有效链接会自动开始；也可按 Enter 或点击“开始收录”。
3. 等待“最近处理”显示完成。无需填写标题、字幕或备注。

系统会自动识别平台并选择路线：

- 微信视频号：腾讯元宝隔离登录解析、下载和本机转写。
- Bilibili：直接粘贴普通公开 BV/AV 链接；P0004 自动走公开 API，不要求登录。
- 抖音：直接粘贴公开视频链接；即使复制到的是带 `modal_id` 的搜索/课程弹层地址，P0004 也会自动转换为对应单视频链接，再创建一次性匿名 Edge/Chrome 会话。不会读取你现有浏览器的 Cookie 或登录态。
- 小红书：从小红书重新点击“分享/复制链接”，原样粘贴完整链接，不要删掉 `xsec_token`。若提示 `link-refresh-required`，重新复制一次完整链接再发送。
- YouTube、快手、TikTok、腾讯视频等其他已识别平台：受管下载器尝试获取单条公开媒体，再本机转写。平台存在提取器不等于私有、会员、付费、地区限制或 DRM 内容可用。
- 其他公开网页：安全读取公开信息；不能下载时保存链接笔记并明确标记降级。

页面会给出明确结果：已写入、处理中、已经收录过，或失败且可重试。任务成功后 Markdown 包含公开信息、时间线和完整字幕；同一规范链接不会创建第二份笔记。

视频默认保留在“设置与恢复”中配置的下载视频保存位置，并继续使用 `<capture_id>\<sha256>.<ext>` 避免覆盖。例如可以配置为 `D:\KnowledgeBase\VideoMedia`。点击设置中的“打开视频目录”可直接进入该文件夹；如只想保留 Markdown，可取消“成功后保留视频”。

## 外出时用手机发给 Hermes

电脑端只需保持两项服务运行：Hermes Gateway 和视频知识捕手。外出看到视频后，在手机的 Hermes 对话中直接发送一条完整公开链接，不需要再填写标题、字幕、备注或平台。

Hermes 回执有五种明确含义：

- `completed`：视频已下载、离线转写并写入 Inbox；媒体任务回执会直接写出 Markdown 和保留视频的完整路径。
- `duplicate`：这条规范链接已经收录，没有创建第二份笔记。
- `processing`：家庭电脑已接收但还在下载或转写；记住 `job_id`，稍后发送“查询这个视频任务：<job_id>”。
- `failed`：任务失败，回执包含错误码、登录要求/访问拒绝/无媒体格式等分类、是否可重试和下一步；不要把它当作已经入库，也不要让 Hermes 旁路 P0004 直接写 Markdown。
- `unavailable`：家庭电脑、Hermes Gateway 或 P0004 当前不可连接；开机并启动服务后重新发送原链接。

Hermes 手机入口没有云端暂存队列：电脑关机或休眠时，链接不会被伪装成已排队。Hermes 不直接读取或写入 Obsidian，也不会读取消息平台 Cookie、Token 或密码；所有知识库写入仍由 P0004 在本机完成。

维护者首次安装或升级 M6 集成时运行。`setup:hermes` 会把 P0004 管理的插件和技能目录精确同步到项目版本，并清除其中未声明的旧文件：

```powershell
npm.cmd run setup:hermes
hermes plugins enable video-knowledge-capture --no-allow-tool-override
hermes tools enable video_knowledge_capture --platform feishu
hermes gateway restart
hermes gateway status --deep
```

`feishu` 是当前 Hermes 手机消息入口在配置中的内部平台键，不代表 P0004 直接连接或读取该平台凭据。自动验收命令 `npm.cmd run verify:hermes` 只使用临时 `HERMES_HOME` 和临时 Inbox，不发送手机消息，也不触碰真实知识库。

## 用本机视频或音频自动生成字幕

1. 展开“设置与恢复”，找到“本地文件备用入口”。
2. 首次使用点击“安装 / 修复运行时”。模型约 466 MiB，等待页面显示“转写已就绪”或“全部就绪”。
3. 填写对应的公开来源链接。
4. 选择本机视频或音频；可选填标题和备注。
5. 点击“上传并本地转写”。

任务区会依次显示上传、提取音频、本地转写、写入和清理状态。成功笔记包含：

- `material_source: "local-asr"`
- 识别语言、模型与媒体时长
- 机器转写误差提示
- “时间线”和“完整字幕”章节

成功后临时视频、WAV、SRT 和 JSON 自动删除。失败时媒体保留在应用工作目录，可点击“安全重试”；不再需要时点击“清理媒体”。

## 微信视频号高级模式

微信 `/sph/` 分享页通常只有播放器外壳。V1.1.0 在粘贴视频号链接时自动选择腾讯元宝路线；桌面微信 sidecar 捕获保留为折叠设置中的备用能力。

### 首次启用

1. 先完成 Inbox 配置。
2. 把 `/sph/` 分享链接粘贴到首页。
3. 首次使用若没有元宝会话，应用会打开独立浏览器窗口；手动扫码，窗口自动关闭后重新粘贴同一链接。
4. 等待最近任务完成。任务卡会显示 Markdown 路径和默认保留的视频路径。

同一链接和相同媒体重复执行会复用同一文件，不覆盖不同内容。元宝明文 Cookie 不落盘；独立会话只以 Windows DPAPI 当前用户范围加密保存。

### 桌面微信捕获备用路线

选择“桌面微信实时捕获（备用）”后，才需要安装 / 修复 HTTPS 证书、启动捕获组件，并在组件启动后重新打开和播放目标视频。该路线仍遵守临时目录、失败留痕和安全清理边界。

“组件已运行”不等于视频已就绪。如果任务提示 `No ready WeChat page is available for feed profile`，先关闭视频页再打开并点击“安全重试”。当前微信可能复用组件启动前的旧 SPA 页面；如果仍未连接，需要从系统托盘彻底退出并重启桌面微信，再重新打开目标视频。无需重复安装证书。

命令行 E4 验收必须在正常 Windows 桌面用户会话中运行；Codex 等受限沙箱账号可能只能读取 `%LOCALAPPDATA%` 下的 sidecar 文件，无法更新其 `config.yaml`。推荐命令：

```powershell
npm.cmd run verify:wechat-live -- `
  --url "https://weixin.qq.com/sph/<authorized-id>" `
  --page-timeout-seconds 600
```

已有失败任务时，可将命令改为 `--retry-job "<失败任务 JSON 的绝对路径>"`。验收器只读取该失败任务中的微信来源链接，不把链接复制进新的命令行或日志。

sidecar 首次就绪可能需要约 10 秒，V1.0 等待上限为 30 秒。若进程提前退出，会返回 `WECHAT_SIDECAR_EXITED`；若服务未就绪，会返回 `WECHAT_SIDECAR_START_TIMEOUT`。E4 失败会报告 `retainedAt` 隔离目录供定位和安全重试，成功后该目录自动清理。

### 停止和撤销

- 本次处理结束后点击“停止组件”。
- 不再使用高级模式时取消勾选。
- 要撤销系统信任，点击“卸载 HTTPS 证书”并确认 UAC。
- P0004 不主动改 Windows 系统代理；当前 sidecar 使用针对微信进程的代理。若未来版本需要系统代理，必须先保存并在停止时恢复原值。

## 处理失败记录

先根据提示修复 Inbox 路径或写入权限，再点击失败记录右侧的“安全重试”。

- 成功后记录显示“已处理”。
- 即使重复点击重试，也只会保留一份笔记。
- 原始记录保留在本地，便于以后定位问题。

## 停止与再次启动

- 停止：在启动窗口按 `Ctrl+C`，或关闭该窗口。
- 再次启动：重新双击 `start-video-capture.cmd`。
- 如果应用已经在运行，再次双击只会重新打开现有页面，不会启动第二份服务。
- 如果刚更新过应用而旧版本仍在运行，启动器会提示关闭原启动窗口；关闭后再双击即可使用新版。
- Inbox 配置会保留，不需要每次重新填写。

## 安全边界

- 服务仅监听本机 `127.0.0.1`。
- 内容获取会访问你提交的公开网页；微信视频号仅在你提交 `/sph/` 链接并完成元宝隔离登录后使用该独立会话。
- 不读取或保存用户的 Token、浏览器 Cookie、密码和 API Key。抖音所需匿名 Cookie 只来自任务级隔离浏览器，放在临时文件中并在任务结束时删除。
- 已识别的公开视频平台只下载单个非直播媒体，不加载用户下载器配置，不处理播放列表、私有、会员、付费内容或 DRM。
- 媒体只在本机处理，不重新托管；失败任务保留在隔离工作目录，供安全重试或清理。
- 微信媒体下载 URL、解密 key 和临时令牌不会写入 Markdown 或公开任务响应。
- 微信高级模式的根证书可从界面或 `npm.cmd run wechat:uninstall-cert` 精确卸载。
- 本机、私网、链路本地和非标准端口会被拒绝；TUN 假 IP 只对已允许的视频平台域名例外，未知域名仍拒绝。
- 真实 Inbox 由用户自己选择；自动验收只使用系统临时目录。
- 元宝明文 Cookie 不落盘；本地只保存 Windows DPAPI 当前用户加密记录。媒体保留记录只包含本地路径、SHA-256 和文件大小。

## 首次人工验收清单

- [ ] 双击启动脚本后浏览器能打开首页。
- [ ] 页面文字清晰，没有明显遮挡或横向滚动。
- [ ] 保存一个测试 Inbox 后显示“已就绪”。
- [ ] 首页只看到一个链接框、一个主按钮；设置与恢复默认折叠。
- [ ] 粘贴一条短公开视频后，任务完成并生成带时间线与完整字幕的 Markdown。
- [ ] 再次提交同一链接后提示已经收录过，不会重复插入。
- [ ] 关闭启动窗口后，本地页面无法继续访问。
- [ ] 设置中显示五项运行时已就绪。
- [ ] 默认保留的视频可以完整播放；关闭保留选项后再次用其他短媒体测试，成功任务只留下 Markdown。
- [ ] 点击“打开视频目录”后，资源管理器进入当前配置的保留目录。
- [ ] 若验收微信高级模式：证书安装和卸载均成功；打开一条已授权视频后只生成一份临时测试笔记；停止后 2025/2026 无监听。
- [ ] 从手机向 Hermes 发送一条获授权公开视频链接，收到 `completed` 或 `duplicate` 回执；若先收到 `processing`，稍后用同一 `job_id` 查询到终态。
- [ ] Hermes 的媒体终态回执直接显示视频完整路径；若路径缺失，回执明确提示到家庭电脑查看任务详情。
